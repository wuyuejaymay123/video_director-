# 可复制的任务指令

先按 [平台指南](agents.md) 加载技能或发送通用提示词，再使用下列指令。所有省略号替换为自己的素材。

## 只有主题

```text
用 video-script-director 做一条完整短视频方案。
主题：为什么知识讲得很多，别人还是听不进去。
受众：刚开始做知识口播的人。平台：抖音。目标：60 秒。
语气：像朋友交流，有一组具体的前后表达对比。
交付纯口播、排练预估时间线、表演/镜头、剪辑交接和素材清单。
明确标出共鸣、举例、自问自答的位置，不为了齐全硬塞技巧。
这次只出方案，不生成图片。
```

## 优化完整文案

```text
用 video-script-director 优化下面这篇稿子，保持主题和事实不变。
目标 90 秒，保留我的个人语气。删掉重复和空话，增加必要的具体例子。
输出完整口播和逐段拍摄/剪辑要求，并简要解释关键改动。
没有证据的数据不能补写；没有实录的时间线标为预估。
原文：……
```

## 融合喜欢的片段

```text
主题：把专业知识讲明白。观众：知识博主。目标 90 秒。
把“别让观众替你翻译。”原样融入，一字不改。
下面这段只保留意思，可以润色：……
请用 video-script-director 补齐完整文章和自然衔接，
说明每个片段放在哪里、改了什么，给时间线、表演和剪辑要求。
```

## 需要实际配图

```text
根据本次方案，为确实有助于理解的段落配图。
若当前有可用图像工具，请实际生成并展示结果，记录真实文件位置。
没有图像工具则给完整提示词、使用段落、构图和替代办法，标为待生成。
软件操作、数据截图使用真实素材，不能用生成图冒充。
```

## 交给剪辑 Agent

```text
请读取导演方案、剪辑交接单和 edit-brief.json，并检查我提供的实录素材。
这些计划时码是拍摄前预估，先按实际台词、停顿和音轨重新对齐。
优先落实 priority=must 的剪辑节点，以 anchor 原文和 occurrence 次数定位，
不要把计划秒数当成源视频秒数；增删或变速后更新成片时间映射。
根据每个节点的视觉/声音意图处理，保留共鸣处的留白和自然人声。
缺少的真实截图/素材列出来，按方案中的 fallback 处理，不伪造素材。
先输出当前工具能够执行的剪辑计划，并按我的本次授权完成预览或成片。
```
