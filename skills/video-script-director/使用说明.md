# 短视频文案与镜头导演：通用使用说明

同一套方法支持整稿优化、主题成稿、好句融合，输出可照拍的口播、情绪/镜头时间线、配图与剪辑要求。核心不依赖 Codex，也不需要 API Key。Python 脚本只是可选的校验/导出助手。

## 最快开始

支持 Skill 的 Agent：加载 `video-script-director` 文件夹，保留 SKILL.md、references、scripts 的相对位置。用自然语言说“用短视频文案与镜头导演处理下面的内容”即可；平台自己的 `$` 或 `/` 调用语法不是核心要求。

普通聊天助手：复制或上传 `通用提示词.md`，随后附上主题/文案。若不能读取 Markdown 附件，直接粘贴文件文字。它已包含全部创作方法和输出格式，不需要让聊天助手访问你的电脑目录。

## 三种开场指令

**整稿优化**

> 用短视频文案与镜头导演优化下面这篇稿子。主题不变，面向第一次做口播的人，目标 90 秒。保留我的个人语气，给我纯口播稿、逐段怎么说怎么拍、配图和剪辑交接。正文：……

**只有主题**

> 主题：为什么我一开摄像头就像在念稿。观众是刚开始拍视频的人，小红书，60 秒。请直接成稿，安排示范对比、自问自答和共鸣，并按实际可用的工具生成需要的配图。没有生图工具时把待生成部分标清。

**融合好句**

> 主题：怎么把知识讲得让人愿意听。请围绕这个主题写一篇 90 秒稿子，把“别让观众替你翻译。”原样融入。其他片段可以润色：……。给完整的拍摄时间线和重点剪辑要求。

已有明确要求就直接附上，没写的由助手做合理假设。原句不能动时请写“一字不改”；时长、平台、风格也可以在过程中改。

## 拿到什么

1. 纯口播稿：直接进入提词器。
2. 拍摄导演表：每段预计秒数、完整台词、情绪、重音、停顿、表情动作、景别和露脸方式。
3. 剪辑交接单：说到哪个词时怎么切、字幕/动效怎么动、声音怎么处理、何时恢复。
4. 素材清单和实际媒体：图片区分已生成、待生成、待补实录；提示词不冒充图片。
5. 通用 JSON：下游 Agent 可读取和改编成它自己的剪辑计划；这不是剪映等软件的直接导入工程。

没有实录的时间线只是排练估算。拍完后连同真实视频/录音交给剪辑助手，先按台词和重音重新对齐，不能直接照抄预计时码。

## 可选的本地导出

Python 3.10+，只用标准库，无需 pip 安装运行依赖。终端进入本技能文件夹，再执行（路径换成你的实际路径）：

```sh
python scripts/director_package.py /path/to/director-plan.json --check
python scripts/director_package.py /path/to/director-plan.json --out /path/to/output
```

系统命令是 `python3` 时相应替换。路径有空格请加引号。默认保护已有输出，确需更新同一版时添加 `--overwrite`。

无 Python、无写文件工具也能按模板产出全部内容，只是不能声称程序已校验或文件已保存。转移到另一台设备时应连同素材文件一起转移，并重新设置真实路径。

包内 `examples/topic/director-plan.json` 是一个完整的 60 秒主题成稿示例，可直接用上述脚本检查/导出；其中配图明确标为 planned，仅示范如何交接素材任务，没有伪称图片已生成。
